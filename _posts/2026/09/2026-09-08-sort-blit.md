## ブリットソートを使用する

ブリットソート (`blitsort`) は、固定長の小さなスワップ領域と配列回転を使い、安定かつほぼインプレースに整列するハイブリッド比較ソートである。

整列度が低い区間では回転クイックソート、整列度が高い区間では回転マージソートを使い分ける。

回転クイックではピボットで安定分割して再帰する。区間がスワップ以下なら二重書き込みで分け、それより長い区間は半分に再帰したあと中央帯を回転でつなぐ。回転マージでは、隣接する整列済みランの左中央を取り、右ランでそれ未満の個数を二分探索してから回転し、スワップに収まるまで小さくして安定マージする。

本記事では高速な三区間回転や単境界の二分探索、分岐の少ない分割の代わりに、わかりやすい回転・通常の二分探索・二重書き込み分割を用いて簡略化している。小区間の仕上げは挿入ソート、回転マージを打ち切ったあとは通常の安定マージで代用する。

1.  **アナライザ**: 全体が昇順なら何もしない。降順（同値を含む非増加）なら反転して終了する。配列を 4 分割し、各区間の隣接昇順ペアが半数超ならその区間を回転マージソートで仕上げる。
2.  **回転クイックソート**: 9 点の準中央値をピボットにし、スワップ長以下なら安定な二重書き込み分割、それより長い区間は半分ずつ分割してから中央帯を回転して `<= ピボット` を前方へ集める。
3.  **等値の第二走査**: 右側が空（すべて `<= ピボット`）なら、`< ピボット` だけを前方へ寄せて等値帯を再帰から外す。
4.  **不均衡フォールバック**: 左右の長さ比が 1:16 を超えて偏ったら、両側を回転マージソートする。最悪計算量を $$O(n \log n)$$ に抑えるためのガードである。
5.  **回転マージ**: 左ランの中央要素を取り、右ランでそれ未満の個数を二分探索し、中央ブロックを回転してから左右を再帰する。どちらかがスワップに収まったら通常の安定マージで打ち切る。
6.  **小区間**: 要素数が閾値未満なら挿入ソートで仕上げる。スワップは既定で 512 要素（配列がそれより短ければ配列長）に固定する。

```pseudocode
procedure blit_rotate(A, left, swap)
  // 先頭 left 個を末尾へ移す。短い側が swap に収まるなら block move、
  // そうでなければ 3 回の reverse（三区間回転の説明用代用）

procedure blit_stable_partition(A, swap, pivot)
  if length(A) > length(swap) then
    h := length(A) / 2
    l := blit_stable_partition(A[0 .. h), swap, pivot)
    r := blit_stable_partition(A[h .. end), swap, pivot)
    blit_rotate(A[l .. h+r), h - l, swap)
    return l + r
  // さもなくば swap へ退避して <= pivot を前方へ安定に書き戻す

procedure blit_rotate_merge_block(A, left_len, right_len, swap)
  if A[left_len-1] <= A[left_len] then return
  if left_len <= length(swap) or right_len <= length(swap) then
    stable_merge via swap; return
  rblock := left_len / 2; lblock := left_len - rblock
  left := lower_bound(A[left_len ..), A[lblock])
  blit_rotate(A[lblock .. lblock+rblock+left), rblock, swap)
  blit_rotate_merge_block(A[0 .. lblock+left), lblock, left, swap)
  blit_rotate_merge_block(A[lblock+left ..), rblock, right_len-left, swap)

procedure blitsort(A)
  if A is sorted then return
  if A is reverse-sorted then reverse(A); return
  swap := buffer of min(512, length(A))
  for each quarter Q of A
    if ordered_pairs(Q) > half then blit_rotate_mergesort(Q, swap)
  if A is sorted then return
  blit_partition_sort(A, swap)
```

最良は整列済み検出により $$O(n)$$、平均・最悪は $$O(n \log n)$$ である。補助メモリは固定長スワップ（既定 512 要素）に加え、再帰の深さ分の $$O(\log n)$$ のスタックを使う。

以下のデモでは視認性のため挿入閾値を 4、スワップを 4、不均衡判定を 1/4 に緩めている。

<script>
window.DemoSort && DemoSort.boot('blit-sort-demo', function (root) {
  /** デモ用に小区間・スワップ・不均衡比を緩め、回転が見えやすくしている。 */
  const INSERTION_THRESHOLD = 4;
  const SWAP_SIZE = 4;
  const UNBALANCE_RATIO = 4;

  function isSorted(a) {
    for (let i = 1; i < a.length; i++) {
      if (a[i - 1] > a[i]) return false;
    }
    return true;
  }

  function isReverseSorted(a) {
    for (let i = 1; i < a.length; i++) {
      if (a[i - 1] < a[i]) return false;
    }
    return true;
  }

  function orderedPairs(a, lo, hi) {
    let c = 0;
    for (let i = lo + 1; i <= hi; i++) {
      if (a[i - 1] <= a[i]) c++;
    }
    return c;
  }

  function median3Idx(a, i, j, k) {
    const x = a[i];
    const y = a[j];
    const z = a[k];
    if (x < y) {
      if (y < z) return j;
      if (x < z) return k;
      return i;
    }
    if (x < z) return i;
    if (y < z) return k;
    return j;
  }

  function quasimedian9(a, lo, hi) {
    const n = hi - lo + 1;
    if (n < 9) return a[lo + Math.floor(n / 2)];
    const step = Math.floor(n / 8);
    const i0 = lo;
    const i1 = lo + step;
    const i2 = lo + step * 2;
    const i3 = lo + step * 3;
    const i4 = lo + step * 4;
    const i5 = lo + step * 5;
    const i6 = lo + step * 6;
    const i7 = lo + step * 7;
    const i8 = hi;
    const m0 = median3Idx(a, i0, i1, i2);
    const m1 = median3Idx(a, i3, i4, i5);
    const m2 = median3Idx(a, i6, i7, i8);
    return a[median3Idx(a, m0, m1, m2)];
  }

  function generateSteps(initial) {
    const a = initial.slice();
    const steps = [];
    const n = a.length;
    const swap = new Array(Math.min(SWAP_SIZE, Math.max(n, 1))).fill(0);

    function pushPhase(text) {
      steps.push({ kind: 'phase', text: text, arr: a.slice() });
    }

    function pushArr(kind, extra) {
      const s = Object.assign({ kind: kind, arr: a.slice() }, extra || {});
      steps.push(s);
    }

    function swapAt(i, j, phase) {
      if (i === j) return;
      const t = a[i];
      a[i] = a[j];
      a[j] = t;
      steps.push({ kind: 'swap', lo: i, hi: j, phase: phase, arr: a.slice() });
    }

    function reverseRange(lo, hi, phase) {
      let i = lo;
      let j = hi;
      while (i < j) {
        swapAt(i, j, phase);
        i++;
        j--;
      }
    }

    function insertionSort(lo, hi) {
      for (let i = lo + 1; i <= hi; i++) {
        const key = a[i];
        let j = i - 1;
        steps.push({
          kind: 'range',
          lo: lo,
          hi: hi,
          focus: i,
          arr: a.slice(),
          caption: '挿入ソート',
        });
        while (j >= lo && a[j] > key) {
          a[j + 1] = a[j];
          j--;
          pushArr('write', { lo: lo, hi: hi, focus: j + 1, caption: '挿入ソートでずらす' });
        }
        a[j + 1] = key;
        pushArr('write', { lo: lo, hi: hi, focus: j + 1, caption: '挿入ソートで確定' });
      }
    }

    function rotate(lo, hi, left) {
      const len = hi - lo + 1;
      if (left <= 0 || left >= len) return;
      const right = len - left;
      pushArr('rotate', {
        lo: lo,
        hi: hi,
        left: left,
        caption: `区間 ${lo} … ${hi} を ${left} 要素ぶん回転`,
      });
      if (left <= right && left <= swap.length) {
        for (let i = 0; i < left; i++) swap[i] = a[lo + i];
        for (let i = 0; i < right; i++) a[lo + i] = a[lo + left + i];
        for (let i = 0; i < left; i++) a[lo + right + i] = swap[i];
      } else if (right <= swap.length) {
        for (let i = 0; i < right; i++) swap[i] = a[lo + left + i];
        for (let i = left - 1; i >= 0; i--) a[lo + right + i] = a[lo + i];
        for (let i = 0; i < right; i++) a[lo + i] = swap[i];
      } else {
        reverseRange(lo, lo + left - 1, 'rotate');
        reverseRange(lo + left, hi, 'rotate');
        reverseRange(lo, hi, 'rotate');
        return;
      }
      pushArr('rotate_done', {
        lo: lo,
        hi: hi,
        caption: '回転完了',
      });
    }

    function lowerBound(lo, hi, needle) {
      let L = lo;
      let R = hi + 1;
      while (L < R) {
        const mid = L + Math.floor((R - L) / 2);
        if (a[mid] < needle) L = mid + 1;
        else R = mid;
      }
      return L - lo;
    }

    function mergeWithSwap(lo, mid, hi) {
      const leftLen = mid - lo + 1;
      for (let i = 0; i < leftLen; i++) swap[i] = a[lo + i];
      let i = 0;
      let j = mid + 1;
      let k = lo;
      while (i < leftLen && j <= hi) {
        if (swap[i] <= a[j]) {
          a[k] = swap[i];
          i++;
        } else {
          a[k] = a[j];
          j++;
        }
        k++;
        pushArr('merge', { lo: lo, hi: hi, focus: k - 1, caption: 'スワップ経由の安定マージ' });
      }
      while (i < leftLen) {
        a[k] = swap[i];
        i++;
        k++;
        pushArr('merge', { lo: lo, hi: hi, focus: k - 1, caption: '左ランの残りを書き戻す' });
      }
    }

    function mergeBackward(lo, mid, hi) {
      const rightLen = hi - mid;
      for (let i = 0; i < rightLen; i++) swap[i] = a[mid + 1 + i];
      let i = mid;
      let j = rightLen;
      let k = hi;
      while (i >= lo && j > 0) {
        if (a[i] > swap[j - 1]) {
          a[k] = a[i];
          i--;
        } else {
          j--;
          a[k] = swap[j];
        }
        k--;
        pushArr('merge', { lo: lo, hi: hi, focus: k + 1, caption: '右ラン側の安定マージ' });
      }
      while (j > 0) {
        j--;
        a[k] = swap[j];
        k--;
        pushArr('merge', { lo: lo, hi: hi, focus: k + 1, caption: '右ランの残りを書き戻す' });
      }
    }

    function rotateMergeBlock(lo, mid, hi) {
      const leftLen = mid - lo + 1;
      const rightLen = hi - mid;
      if (leftLen === 0 || rightLen === 0) return;
      if (a[mid] <= a[mid + 1]) return;
      pushArr('range', {
        lo: lo,
        hi: hi,
        focus: mid,
        caption: `回転マージ: 左 ${leftLen} / 右 ${rightLen}`,
      });
      if (leftLen <= swap.length) {
        mergeWithSwap(lo, mid, hi);
        return;
      }
      if (rightLen <= swap.length) {
        mergeBackward(lo, mid, hi);
        return;
      }
      const rblock = Math.floor(leftLen / 2);
      const lblock = leftLen - rblock;
      const centerIdx = lo + lblock;
      const left = lowerBound(mid + 1, hi, a[centerIdx]);
      const right = rightLen - left;
      if (left > 0) {
        rotate(centerIdx, centerIdx + rblock + left - 1, rblock);
        rotateMergeBlock(lo, lo + lblock - 1, lo + lblock + left - 1);
        const base = lo + lblock + left;
        rotateMergeBlock(base, base + rblock - 1, base + rblock + right - 1);
      } else if (right > 0) {
        rotateMergeBlock(centerIdx, centerIdx + rblock - 1, hi);
      }
    }

    function rotateMergesort(lo, hi) {
      const len = hi - lo + 1;
      if (len <= 1) return;
      const block0 = Math.min(INSERTION_THRESHOLD, swap.length);
      for (let i = lo; i <= hi; i += block0) {
        insertionSort(i, Math.min(i + block0 - 1, hi));
      }
      let block = block0;
      while (block < len) {
        for (let start = lo; start <= hi; ) {
          const mid = start + block - 1;
          if (mid >= hi) break;
          const end = Math.min(mid + block, hi);
          rotateMergeBlock(start, mid, end);
          start = end + 1;
        }
        block *= 2;
      }
    }

    function stablePartition(lo, hi, pivot) {
      const len = hi - lo + 1;
      if (len === 0) return 0;
      if (len > swap.length) {
        const h = lo + Math.floor(len / 2);
        const l = stablePartition(lo, h - 1, pivot);
        const r = stablePartition(h, hi, pivot);
        rotate(lo + l, h + r - 1, h - (lo + l));
        return l + r;
      }
      pushArr('pivot', {
        lo: lo,
        hi: hi,
        pivot: pivot,
        caption: `ピボット ${pivot} で安定分割`,
      });
      for (let i = 0; i < len; i++) swap[i] = a[lo + i];
      let left = 0;
      for (let i = 0; i < len; i++) {
        if (swap[i] <= pivot) left++;
      }
      let l = 0;
      let r = left;
      for (let i = 0; i < len; i++) {
        const x = swap[i];
        if (x <= pivot) {
          a[lo + l] = x;
          l++;
        } else {
          a[lo + r] = x;
          r++;
        }
        pushArr('write', {
          lo: lo,
          hi: hi,
          focus: lo + (x <= pivot ? l - 1 : r - 1),
          caption: 'スワップからの安定な書き戻し',
        });
      }
      return left;
    }

    function partitionSort(lo, hi) {
      const len = hi - lo + 1;
      if (len <= 1) return;
      if (len <= INSERTION_THRESHOLD) {
        insertionSort(lo, hi);
        return;
      }
      const pivot = quasimedian9(a, lo, hi);
      const left = stablePartition(lo, hi, pivot);
      const right = len - left;
      if (right === 0) {
        pushPhase(`等値の第二走査（ピボット ${pivot}）`);
        for (let i = 0; i < len; i++) swap[i] = a[lo + i];
        let lt = 0;
        for (let i = 0; i < len; i++) {
          if (swap[i] < pivot) {
            a[lo + lt] = swap[i];
            lt++;
          }
        }
        let eq = lt;
        for (let i = 0; i < len; i++) {
          if (swap[i] === pivot) {
            a[lo + eq] = swap[i];
            eq++;
          }
        }
        for (let i = 0; i < len; i++) {
          if (swap[i] > pivot) {
            a[lo + eq] = swap[i];
            eq++;
          }
        }
        pushArr('write', { lo: lo, hi: hi, caption: '等値帯を再帰から外す' });
        if (lt > 1) partitionSort(lo, lo + lt - 1);
        return;
      }
      const unbalanced =
        (left > 0 && left < Math.floor(len / UNBALANCE_RATIO)) ||
        (right > 0 && right < Math.floor(len / UNBALANCE_RATIO));
      if (unbalanced) {
        pushPhase('不均衡のため回転マージソートへ切替');
        if (left > 1) rotateMergesort(lo, lo + left - 1);
        if (right > 1) rotateMergesort(lo + left, hi);
        return;
      }
      if (left > 1) partitionSort(lo, lo + left - 1);
      if (right > 1) partitionSort(lo + left, hi);
    }

    if (isSorted(a)) {
      steps.push({ kind: 'done', arr: a.slice() });
      return steps;
    }
    if (isReverseSorted(a)) {
      pushPhase('降順を検出したため反転');
      reverseRange(0, n - 1, 'reverse');
      steps.push({ kind: 'done', arr: a.slice() });
      return steps;
    }

    const q = Math.floor(n / 4);
    if (q >= 2) {
      const bounds = [0, q, q * 2, q * 3, n];
      for (let s = 0; s < 4; s++) {
        const lo = bounds[s];
        const hi = bounds[s + 1] - 1;
        if (hi - lo < 1) continue;
        const pairs = hi - lo;
        if (orderedPairs(a, lo, hi) * 2 > pairs) {
          pushPhase(`区間 ${lo} … ${hi} の整列度が高いため回転マージソート`);
          rotateMergesort(lo, hi);
        }
      }
      if (isSorted(a)) {
        steps.push({ kind: 'done', arr: a.slice() });
        return steps;
      }
    }

    pushPhase('回転クイックソート（安定分割＋回転）');
    partitionSort(0, n - 1);
    steps.push({ kind: 'done', arr: a.slice() });
    return steps;
  }

  DemoSort.attachPlayback({
    root: root,
    dataAttr: 'data-blit',
    initialValues: [5, 2, 8, 1, 9, 3, 6, 14, 4, 11, 7, 13, 10, 12, 15],
    initialCaption:
      'ブリットソートのデモ（回転マージ・安定分割の回転組立・固定スワップ）',
    barClass: 'sort-demo__bar',
    generateSteps: generateSteps,
    applyStep: async function (api, s) {
      const barsEl = api.barsEl;

      function prefersReducedMotion() {
        try {
          return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
        } catch (_e) {
          return false;
        }
      }

      function sameMultiset(a, b) {
        if (a.length !== b.length) return false;
        const sa = a.slice().sort(function (x, y) {
          return x - y;
        });
        const sb = b.slice().sort(function (x, y) {
          return x - y;
        });
        for (let i = 0; i < sa.length; i++) {
          if (sa[i] !== sb[i]) return false;
        }
        return true;
      }

      async function mountBarsFlip(next) {
        const kids = Array.prototype.slice.call(barsEl.children);
        const prev = kids.map(function (el) {
          return Number(el.title);
        });
        if (
          prev.length !== next.length ||
          !sameMultiset(prev, next) ||
          prefersReducedMotion()
        ) {
          api.mountBars(barsEl, next);
          return;
        }
        let unchanged = true;
        for (let i = 0; i < prev.length; i++) {
          if (prev[i] !== next[i]) {
            unchanged = false;
            break;
          }
        }
        if (unchanged) {
          api.mountBars(barsEl, next);
          return;
        }

        const beforeRects = kids.map(function (el) {
          return el.getBoundingClientRect();
        });
        const byValue = new Map();
        for (let i = 0; i < kids.length; i++) {
          const v = Number(kids[i].title);
          if (!byValue.has(v)) byValue.set(v, []);
          byValue.get(v).push({ el: kids[i], rect: beforeRects[i] });
        }
        api.mountBars(barsEl, next);
        const afterKids = Array.prototype.slice.call(barsEl.children);
        afterKids.forEach(function (el, idx) {
          const v = next[idx];
          const bucket = byValue.get(v);
          if (!bucket || bucket.length === 0) return;
          const prevEl = bucket.shift();
          const after = el.getBoundingClientRect();
          const dx = prevEl.rect.left - after.left;
          const dy = prevEl.rect.top - after.top;
          if (dx === 0 && dy === 0) return;
          el.style.transform = 'translate(' + dx + 'px,' + dy + 'px)';
          el.style.transition = 'transform 0s';
          requestAnimationFrame(function () {
            el.style.transition = 'transform 180ms ease';
            el.style.transform = '';
          });
        });
        await DemoSort.wait(api.stepPauseMs ? api.stepPauseMs : 180);
      }

      if (s.kind === 'phase') {
        await mountBarsFlip(s.arr);
        DemoSort.clearRoles(barsEl);
        api.setCaption(s.text);
        return;
      }
      if (
        s.kind === 'range' ||
        s.kind === 'write' ||
        s.kind === 'merge' ||
        s.kind === 'pivot' ||
        s.kind === 'rotate' ||
        s.kind === 'rotate_done'
      ) {
        await mountBarsFlip(s.arr);
        const pairs = [];
        if (typeof s.lo === 'number' && typeof s.hi === 'number') {
          for (let k = s.lo; k <= s.hi; k++) pairs.push([k, 'compare']);
        }
        if (typeof s.focus === 'number') pairs.push([s.focus, 'swap']);
        DemoSort.assignRoles(barsEl, pairs);
        api.setCaption(s.caption || '');
        return;
      }
      if (s.kind === 'swap') {
        const pre = s.arr.slice();
        const tmp = pre[s.lo];
        pre[s.lo] = pre[s.hi];
        pre[s.hi] = tmp;
        const current = Array.prototype.map.call(barsEl.children, function (el) {
          return Number(el.title);
        });
        const matchesPre =
          current.length === pre.length &&
          current.every(function (v, i) {
            return v === pre[i];
          });
        if (!matchesPre) {
          api.mountBars(barsEl, pre);
        }
        DemoSort.assignRoles(barsEl, [
          [s.lo, 'swap'],
          [s.hi, 'swap'],
        ]);
        let swapCaption = '交換しています…';
        if (s.phase === 'reverse') swapCaption = '降順の反転';
        else if (s.phase === 'rotate') swapCaption = '回転のための反転';
        api.setCaption(swapCaption);
        await DemoSort.flipSwap(barsEl, s.lo, s.hi);
        DemoSort.clearRoles(barsEl);
        return;
      }
      if (s.kind === 'done') {
        api.mountBars(barsEl, s.arr);
        DemoSort.clearRoles(barsEl);
        api.setCaption('ソート完了');
      }
    },
    stepPauseMs: 240,
  });
});

## 類似アルゴリズムとの相違点

[フラックスソート](/2026/08/18/sort-flux.html)は安定な二重書き込み分割と最大 $$O(n)$$ の補助配列を使う。ブリットソートは同じ安定分割の発想を、固定スワップ＋回転の組立に落とし込み、補助メモリを定数寄りに抑える。

[クラムソート](/2026/08/23/sort-crum.html)はフルクラム分割で不安定・インプレース寄りにする。ブリットソートは安定性を保ったまま回転で区間を寄せる点が対照的である。

[クワッドソート](/2026/08/17/sort-quad.html)はボトムアップのクワッドマージが本体である。ブリットソートは整列度が高いときだけ回転マージへ寄せ、ランダム寄りでは回転クイックを主とする。

[ウィキソート](/2026/05/31/sort-wiki.html)や[グレイルソート](/2026/06/01/sort-grail.html)も小さなバッファで安定なインプレース寄りマージを目指すが、ブロックマージと内部バッファの設計が中心である。ブリットソートはクイック型の分割と回転マージのハイブリッドである。
