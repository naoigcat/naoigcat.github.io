## コマンド履歴を逆方向検索する

Bashで`Ctrl-r`を押して検索モードに入り、コマンドの一部を入力すると、以前実行したコマンドを履歴から検索できる。

`Ctrl-r`を押すたびに、検索条件に一致する一つ前のコマンドが表示される。

`Enter`を押すと表示中のコマンドが実行され、矢印キーを押すと表示中のコマンドを入力欄に残したまま検索モードが終了する。

```bash
$ echo 1
$ ⌃r
(reverse-i-search)`e': echo 1
```

## スクリーンロックのキーを解除する

スクリーンロックに割り当てられているキーを確認する。

```bash
stty -a
...
        stop = ^S; ...
```

`stop = ^S`であれば`Ctrl-s`が割り当てられているため下記コマンドで解除する。

```bash
stty stop undef
```

`= <undef>`になっていることを確認する。

```bash
stty -a
...
        stop = <undef>; ...
```

これを行うことで検索モードで`Ctrl-s`を押すと一つ後のコマンドが表示されるようになる。

Bashにログインするたびにリセットされるため`.bash_profile`に追加しておく。
